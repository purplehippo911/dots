# My personal arch-linux dotfiles:

## Requirements:
- sudo or root permissions
- arch linux
- git
- internet/ethernet ofc

## Installation

**Clone this repo:**

```sh
git clone https://github.com/purplehippo911/dots.git
```

**Then execute the installer:**

```sh
./dots/install

```

## File structure
- archive: files dont usually use but want to save.
- proj: working projects. move into archive when done.
- src: resources that depend on frequently like assets/images/vids
